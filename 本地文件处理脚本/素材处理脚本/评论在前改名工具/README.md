# 评论在前改名工具

用途：把当前文件夹及所有子文件夹里的文件、文件夹名称，从 `赞1评4` 改成 `评4赞1`，方便先看评论数。

## 一键使用

把整个 `评论在前改名工具` 文件夹放到要处理的素材目录里，双击：

```text
一键改名-评论在前.bat
```

它会处理这个工具所在文件夹下面的所有文件和文件夹，并在 `rename-logs` 里生成改名日志。

## 预览模式

想先看会改哪些名字，可以打开 PowerShell 后运行：

```powershell
.\swap-like-comment-prefix.ps1 -Preview
```

## 规则

- `赞1评4xxx` -> `评4赞1xxx`
- `赞10评080个游戏` -> `评0赞10 80个游戏`
- 如果目标名称已经存在，会跳过，不覆盖原文件。
