# 一键 GPT 作品包

这个工具用于把“一篇笔记”的 GPT 文案和同层图片整理成一个作品包。

当前版本：`1.5.0`

## 使用流程

1. 先把这一篇笔记的图片下载到脚本所在文件夹（通常就是浏览器下载目录）。
2. 再复制 GPT 生成好的文案。
3. 双击 `一键生成作品包.vbs`。
4. 工具会自动生成 TXT、重命名图片、移动到成品库。

需要换成品库时，双击 `设置作品包目录.vbs`，可直接粘贴完整地址，也可点“浏览选择”；在 ChatGPT 油猴菜单里也可以点“设置本地作品包目录”。

## 当前规则

- 只处理脚本所在文件夹这一层的图片，不进入子文件夹。
- 没复制文案时，只提示“请先复制文案”，不整理、不移动。
- 有文案但没图片时，只提示“请先下载作品图”，不生成空包。
- 每组图片都会计算文件 SHA-256，并将排序后的整组哈希集合写入独立历史数据库。图片数量和整组哈希完全相同时直接判定重复，不依赖旧作品文件是否仍存在。
- 文案仍按规范化后的整篇正文计算 SHA-256。文案相同但图片不同会正常创建作品包，并提示“本组有历史相似文案，但图片不同，已继续创建作品包。”
- 图片整组重复时不创建作品包；即使文案略有变化也按重复处理。本次下载图片送入 Windows 回收站，剪贴板文案被清空，并提示“本次为重复下载，已删除本地图片和文案。”
- 默认启用视觉近似预警：使用 64 位 dHash 感知哈希，单图汉明距离不超过 6、整组平均距离不超过 3 且每张图都能一一匹配时停止打包，不删除图片；提示相似历史包并把路径复制到剪贴板。确认不是重复后，重新复制文案并再次运行即可单次放行。
- 历史主库位于成品库的 `_作品历史数据\作品历史数据库.json`，同目录保存上一版备份；下载目录另存隐藏镜像 `.workpkg_history_backup.json`。删除旧作品包不会删除查重记忆。
- 图片会按 `标题_日期时间_01`、`标题_日期时间_02` 这种方式重命名。
- 从 ChatGPT 辅助脚本调用时，会额外生成 `GPT会话溯源.json`，第一项是账号名，第二项是本次对话链接，不改动文案正文。
- 不再创建空白分隔图，作品包里只放文案 TXT 和真实作品图。
- 每篇笔记生成的帖子文件夹使用正常可见名称，例如 `20260720_123456_标题`，不再自动添加前导点。旧版已经生成的点号文件夹仍可继续参与查重和作品集整理。
- 成品库里凑满 14 个帖子文件夹时，会自动整理到正常显示的 `作品集_001`、`作品集_002`，并生成同名 ZIP。
- `workpkg_config.json` 存在时会读取成品库路径、名称、自动整理、压缩和每组数量等设置；配置损坏时自动使用默认值。
- `library_path` 可把成品库放到任意绝对路径；留空时才使用下载目录下的 `library_name` 子目录。
- 作品包先在隐藏暂存目录中生成；中途失败时，已经移动的原图会自动恢复到原位置。
- PowerShell 调试时可使用 `-Preview` 查看目标目录和图片数量，不移动任何文件。

## 历史数据库维护

首次升级到 1.5.0 后，正常打包会自动从现有作品包初始化历史数据库。也可以手动审计：

```powershell
.\make_work_package.ps1 -RebuildHistory -Preview
```

确认结果后，重建数据库并把后出现的重复作品包送入 Windows 回收站：

```powershell
.\make_work_package.ps1 -RebuildHistory -CleanExistingDuplicates
```

重建时按作品文案文件的修改时间从早到晚处理；同一整组图片只保留最早记录。历史 JSON 不保存文案正文和图片内容，只保存哈希、数量、标题、作品包名称和记录时间。

## 给别人安装

把这个目录发给对方后，在 PowerShell 里运行：

```powershell
.\install_work_package_tool.ps1 -TargetFolder "对方下载图片的文件夹" -LibraryName "成品库"
```

下载目录与成品库分开时，可以这样装：

```powershell
.\install_work_package_tool.ps1 `
  -TargetFolder "D:\Download" `
  -LibraryName "团建成品库" `
  -LibraryPath "D:\Projects\MyProject\团建成品库" `
  -RegisterProtocol
```

安装后，对方平时只需要双击目标文件夹里的 `一键生成作品包.vbs`。

## 文件说明

- `一键生成作品包.vbs`：双击入口。
- `make_work_package.ps1`：核心处理脚本。
- `configure_work_package.ps1`：保存成品库目录的后台配置脚本。
- `设置作品包目录.vbs`：双击选择新的成品库目录。
- `install_work_package_tool.ps1`：给别人安装到指定图片下载文件夹。
- `usage_zh.md`：用户使用说明，会在安装时复制到目标文件夹。
- `SKILL.md`：给 AI 助手维护这个工具时使用的规则说明。

## 最近更新

- `1.5.0`：图片整组精确哈希成为主要查重依据；新增独立 JSON 历史数据库、同目录备份和下载目录镜像；支持重建历史、审计并清理已有重复作品；增加视觉近似预警、历史包路径复制和二次运行单次放行。
- `1.4.3`：重复文案不再留下隐藏隔离目录；本次图片送入回收站、剪贴板文案清空，并显示明确提醒。
- `1.4.2`：强化跨浏览器、跨窗口文案去重；统一换行和无意义边缘空白，同时保留正文与标点差异。
- `1.4.1`：目录设置窗口支持直接粘贴完整文件夹地址，同时保留浏览选择。
- `1.4.0`：支持手动选择独立的绝对成品库路径；升级安装保留已有配置；安装器可同步注册 ChatGPT 联动协议，网页端与本地端作为同一工具工作。
- `1.3.4`：恢复正常帖子文件夹名称，不再自动在文件夹名前添加 `.`；兼容历史点号文件夹。
