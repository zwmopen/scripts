# 一键 GPT 作品包

这个工具用于把“一篇笔记”的 GPT 文案和同层图片整理成一个作品包。

当前版本：`1.8.3`

## 使用流程

1. 先把这一篇笔记的图片下载到设置中的“图片下载目录”。
2. 再复制 GPT 生成好的文案。
3. 双击 `一键生成作品包.vbs`。
4. 工具会自动生成 TXT、重命名图片、移动到成品库。

从网页按钮使用时，顺序是“先复制文案，再点击下载并打包”。网页会立刻把文案冻结到该批次的任务 JSON；图片下载较慢时，可以马上切换到其他窗口复制下一份文案。

需要换目录时，双击 `设置作品包目录.vbs`，同时设置图片下载目录和成品库；两个地址都可直接粘贴，也可点“浏览选择”。在 ChatGPT 油猴菜单里也可以打开同一个设置窗口。

## 当前规则

- 只处理设置的图片下载目录最外层，不进入子文件夹。
- 新版网页下载文件包含批次 ID、序号和总数；本地端只处理最新完整批次，缺图时明确提示实际数量和应有数量。
- 协议携带明确批次时只处理指定图片组；多个窗口同时下载时，本地进程排队整理，各自读取独立任务 JSON。
- 成功作品包只包含一个 `GPT作品记录.json`，统一保存任务、查重与会话溯源；精确重复任务保存在程序目录 `任务记录`，便于追溯。
- 没复制文案时，只提示“请先复制文案”，不整理、不移动。
- 有文案但没图片时，只提示“请先下载作品图”，不生成空包。
- 每组图片都会计算文件 SHA-256，并将排序后的整组哈希集合写入独立历史数据库。图片数量和整组哈希完全相同时直接判定重复，不依赖旧作品文件是否仍存在。
- 文案仍按规范化后的整篇正文计算 SHA-256。文案相同但图片不同会正常创建作品包，并提示“本组有历史相似文案，但图片不同，已继续创建作品包。”
- 图片整组重复时不创建作品包；即使文案略有变化也按重复处理。本次下载图片送入 Windows 回收站，剪贴板文案被清空，并提示“本次为重复下载，已删除本地图片和文案。”
- 默认启用视觉近似预警：使用 64 位 dHash 感知哈希，单图汉明距离不超过 6、整组平均距离不超过 3 且每张图都能一一匹配时停止打包，不删除图片；提示相似历史包并把路径复制到剪贴板。确认不是重复后，重新复制文案并再次运行即可单次放行。
- 历史主库位于成品库的 `_作品历史数据\作品历史数据库.json`，同目录保存上一版备份；程序目录另存隐藏镜像 `.workpkg_history_backup.json`。删除旧作品包不会删除查重记忆。
- 图片会按 `标题_日期时间_01`、`标题_日期时间_02` 这种方式重命名。
- 从 ChatGPT 辅助脚本调用时，账号名和本次对话链接写入统一的 `GPT作品记录.json`，不再额外生成溯源文件，也不改动文案正文。
- 不再创建空白分隔图，作品包里只放文案 TXT 和真实作品图。
- 每篇笔记生成的帖子文件夹使用正常可见名称，例如 `20260720_123456_标题`，不再自动添加前导点。旧版已经生成的点号文件夹仍可继续参与查重和作品集整理。
- 默认凑满 14 个帖子文件夹时自动整理到连续编号的作品集，但不生成 ZIP；设置窗口可 DIY 每集数量、自动整理和 ZIP 开关，需要压缩包时再开启。
- 作品集编号保存在独立历史数据库和运行镜像中，并综合整理日志校准；即使旧作品集文件夹和 ZIP 被删除，编号也不会倒退复用。
- `work_package_center.ps1` 提供设置、任务中心和数据恢复界面；支持立即整理剩余作品、命名模板、完成动作、完整数据备份与最近备份恢复。
- `workpkg_config.json` 存在时会读取成品库路径、名称、自动整理、压缩和每组数量等设置；配置损坏时自动使用默认值。
- `image_inbox_path` 指向浏览器图片下载目录，`library_path` 指向成品库；程序、图片收件箱和成品库可以完全分离。
- 作品包先在隐藏暂存目录中生成；中途失败时，已经移动的原图会自动恢复到原位置。
- PowerShell 调试时可使用 `-Preview` 查看目标目录和图片数量，不移动任何文件。

## 历史数据库维护

首次升级到 1.5.0 后，正常打包会自动从现有作品包初始化历史数据库。也可以手动审计：

```powershell
.\make_work_package.ps1 -RebuildHistory -Preview
```

确认结果后，重建数据库并把后出现的重复作品包送入 Windows 回收站：

```powershell
.\make_work_package.ps1 -RebuildHistory -CleanExistingDuplicates
```

重建时按作品文案文件的修改时间从早到晚处理；同一整组图片只保留最早记录。历史 JSON 不保存文案正文和图片内容，只保存哈希、数量、标题、作品包名称和记录时间。

## 给别人安装

普通用户不需要打开 PowerShell：

1. 把完整的“GPT 作品助手傻瓜安装包”ZIP 发给对方。
2. 对方解压后双击 `安装GPT作品助手.vbs`。
3. 安装器会自动安装到当前 Windows 账号、注册 ChatGPT 网页联动协议、创建桌面“GPT作品助手中心”快捷方式并打开设置中心。
4. 对方只需确认图片下载目录和成品库目录，再点“保存全部设置”。
5. 安装器可同时打开网页脚本安装页；浏览器已有 Tampermonkey 时确认安装即可。

需要自定义部署位置的维护者，仍可使用高级安装命令：

```powershell
.\install_work_package_tool.ps1 `
  -TargetFolder "D:\AICode\运行数据\chatgpt-work-package" `
  -ImageInboxPath "D:\Download" `
  -LibraryName "团建成品库" `
  -LibraryPath "D:\Projects\MyProject\团建成品库" `
  -RegisterProtocol
```

安装后，对方可以使用 ChatGPT 网页按钮，也可以双击固定程序目录里的 `一键生成作品包.vbs`。

## 文件说明

- `一键生成作品包.vbs`：双击入口。
- `make_work_package.ps1`：核心处理脚本。
- `configure_work_package.ps1`：保存图片下载目录和成品库目录的后台配置脚本。
- `设置作品包目录.vbs`：双击设置图片下载目录与成品库。
- `安装GPT作品助手.vbs`：普通用户双击安装入口。
- `install_for_user.ps1`：傻瓜安装、桌面入口和首次引导逻辑。
- `install_work_package_tool.ps1`：安装到固定程序目录并注册网页联动协议。
- `usage_zh.md`：用户使用说明，会在安装时复制到目标文件夹。
- `SKILL.md`：给 AI 助手维护这个工具时使用的规则说明。
