# 一键 GPT 作品包

这个工具用于把“一篇笔记”的 GPT 文案和同层图片整理成一个作品包。

当前版本：`1.4.1`

## 使用流程

1. 先把这一篇笔记的图片下载到脚本所在文件夹（通常就是浏览器下载目录）。
2. 再复制 GPT 生成好的文案。
3. 双击 `一键生成作品包.vbs`。
4. 工具会自动生成 TXT、重命名图片、移动到成品库。

需要换成品库时，双击 `设置作品包目录.vbs`，可直接粘贴完整地址，也可点“浏览选择”；在 ChatGPT 油猴菜单里也可以点“设置本地作品包目录”。

## 当前规则

- 只处理脚本所在文件夹这一层的图片，不进入子文件夹。
- 没复制文案时，只提示“请先复制文案”，不整理、不移动。
- 有文案但没图片时，只提示“请先下载作品图”，不生成空包。
- 已经创建过的文案会被查重，重复下载的图片会移动到隐藏隔离目录，不会永久删除。
- 图片会按 `标题_日期时间_01`、`标题_日期时间_02` 这种方式重命名。
- 从 ChatGPT 辅助脚本调用时，会额外生成 `GPT会话溯源.json`，第一项是账号名，第二项是本次对话链接，不改动文案正文。
- 不再创建空白分隔图，作品包里只放文案 TXT 和真实作品图。
- 每篇笔记生成的帖子文件夹使用正常可见名称，例如 `20260720_123456_标题`，不再自动添加前导点。旧版已经生成的点号文件夹仍可继续参与查重和作品集整理。
- 成品库里凑满 14 个帖子文件夹时，会自动整理到正常显示的 `作品集_001`、`作品集_002`，并生成同名 ZIP。
- `workpkg_config.json` 存在时会读取成品库路径、名称、自动整理、压缩和每组数量等设置；配置损坏时自动使用默认值。
- `library_path` 可把成品库放到任意绝对路径；留空时才使用下载目录下的 `library_name` 子目录。
- 作品包先在隐藏暂存目录中生成；中途失败时，已经移动的原图会自动恢复到原位置。
- PowerShell 调试时可使用 `-Preview` 查看目标目录和图片数量，不移动任何文件。

## 给别人安装

把这个目录发给对方后，在 PowerShell 里运行：

```powershell
.\install_work_package_tool.ps1 -TargetFolder "对方下载图片的文件夹" -LibraryName "成品库"
```

下载目录与成品库分开时，可以这样装：

```powershell
.\install_work_package_tool.ps1 `
  -TargetFolder "D:\Download" `
  -LibraryName "团建成品库" `
  -LibraryPath "D:\Projects\MyProject\团建成品库" `
  -RegisterProtocol
```

安装后，对方平时只需要双击目标文件夹里的 `一键生成作品包.vbs`。

## 文件说明

- `一键生成作品包.vbs`：双击入口。
- `make_work_package.ps1`：核心处理脚本。
- `configure_work_package.ps1`：保存成品库目录的后台配置脚本。
- `设置作品包目录.vbs`：双击选择新的成品库目录。
- `install_work_package_tool.ps1`：给别人安装到指定图片下载文件夹。
- `usage_zh.md`：用户使用说明，会在安装时复制到目标文件夹。
- `SKILL.md`：给 AI 助手维护这个工具时使用的规则说明。
