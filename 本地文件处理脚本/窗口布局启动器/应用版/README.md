# 窗口布局启动器 3.0.1

把一组文件夹、网页和软件窗口保存成一个“工作入口”。下次不必逐个寻找窗口，直接点击“开始素材处理”“开始剪辑”“开始写小红书”等任务即可恢复。

## 直接使用

1. 双击 `release\窗口布局启动器.exe`。
2. 第一次打开时选择工作类型。
3. 打开需要的文件夹、网页和软件，把窗口摆到合适位置。
4. 点击“保存为新布局”。
5. 下次在主界面或右下角托盘中直接开始这项工作。

旧版 EXE 仍保留在 `release` 文件夹，新版不会删除旧布局，并兼容原有布局 JSON。

## 3.0 新功能

- 布局预览图：每张卡片显示窗口排列示意图。
- 任务模式：布局显示为“开始素材处理”“开始剪辑”等工作入口。
- 托盘常驻：关闭或最小化主窗口后进入托盘；右键托盘图标可直接选择布局。
- 智能复用：同一路径的文件夹、同一浏览器网页、同一软件窗口优先复用，找不到才新开。
- 布局健康检查：打开前检查失效文件夹、软件路径、网页登录提醒和显示器数量变化。
- 多显示器适配：保存显示器和窗口相对位置；换屏幕后自动映射，避免窗口跑到屏幕外。
- 简单分享：导出、导入单个 JSON 布局包。
- 首次配置向导：引导新用户选择工作类型、摆放窗口并保存。
- 单实例启动：重复双击不会产生多个托盘图标，而是唤醒已经运行的窗口。
- 快捷操作：选中布局后按 `Enter` 打开，`F5` 刷新，`Ctrl+N` 保存新布局。

## 会保存什么

- 文件资源管理器路径、位置和大小。
- Edge / Chrome 网页窗口的浏览器、网页地址、标题特征、位置和大小。
- 普通应用的程序路径、进程名、标题特征、位置和大小。
- 保存时的显示器名称、数量、工作区和每个窗口的相对位置。
- 布局任务类型和保存时间。

## 分享给别人

发送整个 `release` 文件夹，对方可直接运行 EXE；也可以只导出某个布局 JSON。别人电脑上的软件路径和文件夹路径可能不同，导入后先看健康检查，再按对方自己的电脑重新覆盖保存一次即可。

## 产品与界面标准

- 界面采用“拟态悬浮风”：冷灰蓝背景、低饱和浮起卡片和单一蓝色主操作。
- 默认打开居中，无无意义空白和多余滚动条。
- 主内容随窗口变大，小窗口保留可操作区域并允许纵向滚动。
- 中文标题、时间、按钮在高 DPI 下不截断。
- 启动时不自动联网检查更新，避免卡住界面；检查更新由用户主动触发。
