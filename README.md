# scripts

这是 ZWM 的公开脚本与轻量自动化工具仓库，用来集中保存、迭代和发布可以公开安装、复用或自动更新的脚本。

## 仓库边界

这里适合放：

- 油猴脚本；
- 浏览器辅助脚本；
- PowerShell / Python 等轻量自动化脚本；
- 可公开分享的小工具；
- 与脚本配套的配置示例和使用说明。

这里不放：

- 私人资料、账号凭据和密钥；
- 团建客户数据、素材本体和运行缓存；
- 只属于某个私有项目、无法独立复用的业务代码；
- 已有独立源码主仓的完整重复副本。

## 当前在役内容

### ChatGPT 最近对话分组

文件：`chatgpt-conversation-tree.user.js`

安装、浏览器权限和故障排查：[`CHATGPT-HELPER-USAGE.md`](CHATGPT-HELPER-USAGE.md)

功能包括：

- 将 ChatGPT 最近对话按目录分组；
- 支持拖动、嵌套、未分组状态和折叠；
- 支持状态导入、导出和自动备份；
- 提供诊断日志与版本信息；
- 为图片组提供批量下载入口；
- 与本地作品包生成流程衔接；
- 支持 GitHub 云端提示词、离线缓存、防空保护和版本回滚；
- 分组对话默认只走原生无刷新切换，失败时不会强制刷新整页。

> Chrome 138 及以上版本必须在 Tampermonkey 的扩展详情中开启“允许用户脚本”。如果脚本突然完全不显示，应优先检查这个开关；仅开启 Tampermonkey 总开关还不够。

### 团建作品包工作流

相关文件包括 PowerShell 工作包脚本、配置文件和配套说明。

当前能力包括：

- 从剪贴板文案和下载图片生成独立作品包；
- 图片按标题、时间和序号规范重命名；
- 文案查重和重复图片清理；
- 使用暂存目录，避免生成一半的残缺作品包；
- 读取 `workpkg_config.json`；
- 按设定数量自动整理作品集；
- 自动生成 ZIP 和迁移日志；
- 使用锁文件避免并发执行冲突。

### CodexRadar 最佳模型监控

目录：[`tools/codexradar-monitor/`](tools/codexradar-monitor/README.md)

功能包括：

- 定时读取 CodexRadar 最新降智榜；
- 分别判断当前能力最强模型与综合性价比模型；
- 推荐变化时在固定 GitHub Issue 中评论并 `@zwmopen`；
- 将最新快照和历史数据保存到仓库；
- 相同榜单不重复提交、不重复提醒；
- 解析异常时停止发布，避免推送错误结论；
- 无需邮箱密码、外部 Token 或第三方推送密钥。

推送入口：[`scripts#9`](https://github.com/zwmopen/scripts/issues/9)

## 破坏性操作安全约定

涉及移动、覆盖、删除或批量重命名的脚本必须遵守：

- 默认只预览，不直接修改文件；
- Apply / Replace / Undo 使用明确模式和确认令牌；
- 覆盖前先创建可恢复备份；
- 多文件操作使用暂存或事务式提交，任一步失败自动回滚；
- 重复素材只移动到隔离目录，不永久删除；
- 每次执行写入可追溯的 CSV 或日志；
- CI 在 Windows 上验证预览、失败回滚、成功执行和 Undo。

## 单一事实源

- 本仓是公开脚本的源码和发布主入口。
- 某个脚本如果已经拆成独立产品仓，本仓只保留安装入口或跳转说明，不再维护完整副本。
- 私有业务工作台和项目专属工具应留在对应项目仓。

## 维护规则

1. 每次修改脚本时同步更新版本号。
2. 影响已有用户数据的修改，必须保留兼容或迁移逻辑。
3. 自动更新链接依赖当前文件路径，移动文件前必须先检查安装地址。
4. 新增脚本后更新本 README。
5. 重要改动使用分支和 PR，避免直接修改默认分支。
6. 配置文件只提交示例和安全默认值，不提交个人路径、令牌或账号信息。
7. 新增功能、修复故障或发现浏览器兼容问题时，必须主动同步更新对应使用说明，不等待用户再次提醒。
8. 使用说明至少覆盖：安装与更新、必要权限、完整操作流程、数据存储与备份、常见故障、恢复/回滚办法、版本变化和验证结果。
9. 如果问题实际来自浏览器、扩展权限或系统环境，应把识别方法和最短修复路径写入故障排查，避免以后误改脚本。
10. 交付前检查“代码、版本号、文档、测试、云端文件”是否一致；只改文档时不虚增脚本版本号。
