# 鼠标快速语音打字

版本：`0.4.0`

Windows 常驻小软件：把鼠标 `X2` 侧键绑定到微信输入法语音输入。

当前由核心监听、守护恢复和安装任务共同组成一个小程序。后续将沿着“配置驱动的多组鼠标/键盘映射管理器”方向升级，现有 X2 语音输入作为默认预设保留。

它会在后台监听鼠标 `XBUTTON2`，松开侧键时通过 Windows `SendInput` 发送 `左 Ctrl + 左 Alt + O`，对应微信输入法里的“启动语音输入”快捷键。

2026-07-18 兼容性升级：弃用旧式 `keybd_event`，提高新版微信输入法接收模拟快捷键的稳定性；日志会记录 `SendInput` 是否完整发送。

2026-07-19 稳定性升级：鼠标钩子回调改为异步队列处理，并为监听器和守护程序增加单实例锁，避免钩子被 Windows 静默移除或重复进程覆盖 PID。

2026-07-26 v0.4.0：增加钩子与轮询双通道、健康心跳和定时钩子刷新；计划任务移除 VBS 中间层，并增加桌面一键启动修复入口。

## 文件

- `start.cmd`：启动后台监听。
- `stop.cmd`：停止后台监听。
- `install-startup.cmd`：添加到当前用户的 Windows 开机启动。
- `uninstall-startup.cmd`：取消开机启动。
- `watchdog.ps1`：守护脚本，发现后台监听不在时自动拉起。
- `install-watchdog.ps1`：安装计划任务守护，每 5 分钟检查一次。
- `uninstall-watchdog.ps1`：取消计划任务守护。
- `run-hidden.vbs`：旧版隐藏启动兼容文件；v0.4.0 计划任务不再依赖它。
- `wechat-voice-x2-bridge.ps1`：核心脚本。
- `repair-and-status.ps1`：重启监听并检查进程和心跳。
- `install-desktop-shortcut.ps1`：安装桌面“启动修复”入口。
- `SKILL.md`：技能说明，归类为“AI协作 / 人机协同 / 本地脚本型技能”。
- `ASSET.md`：资产归档卡，记录触发链、部署方式、云端位置和恢复方法。

## 使用

1. 保持微信输入法的语音输入快捷键为 `左 Ctrl + 左 Alt + O`。
2. 运行 `install-watchdog.ps1`，安装自启动、守护任务和桌面快捷方式。
3. 此后开机登录应自动运行，日常直接按鼠标 `X2`，不需要点击桌面快捷方式。
4. 只有没反应时，才双击桌面“鼠标语音输入-启动修复”进行手动恢复。
5. `install-startup.cmd` 是旧式启动文件夹入口；推荐优先使用 `install-watchdog.ps1`。

运行时会生成 `.log`、`.pid` 和 `.heartbeat`，它们只保留在本地，不提交到 GitHub。当前不自动下载新版本，升级由 Git 历史和发布分支管理。
